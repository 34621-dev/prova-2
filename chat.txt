## A situação

A escola quer uma API para controlar a reserva de suas salas: laboratórios, auditório, salas de aula. Cada sala tem um código, um nome e uma capacidade, e a escola precisa saber quais estão reservadas e quais estão livres.

## O que a API precisa fazer

- Cadastrar uma sala, listar todas, buscar uma pelo id e excluir.
- Reservar uma sala e liberar uma sala.
- Responder cada situação com o status HTTP certo: sucesso, criado, sem conteúdo, não encontrado, conflito e dados inválidos.

## As regras da escola

- Toda sala cadastrada começa livre.
- O **código é único**: não pode haver duas salas com o mesmo código.
- **Código e nome são obrigatórios**, e a **capacidade precisa ser maior que zero**.
- Uma sala que já está reservada **não pode ser reservada de novo**.
- Só pode ser liberada uma sala que **está reservada**.
- Uma sala reservada **não pode ser excluída**.
- Pedir, reservar, liberar ou excluir uma sala que não existe é um caso de "não encontrado".

## O que o projeto precisa ter

- O projeto **`Escola-base`**, que o professor entrega, e que vocês usam como ponto de partida. Ele já traz Spring Web, Spring Data JPA, validação e banco **H2 em memória**, e já sobe sem nenhuma classe de vocês. Não precisa criar projeto. O arquivo `README.md` dele explica como rodar.
- Organização em camadas, **cada uma no seu pacote, criado por vocês** dentro de `src/main/java/escola`: `model`, `repository`, `service` e `controller`. O projeto base não traz essas pastas prontas.
- As regras da escola ficam na **Service**. O **Controller** só recebe a requisição, chama a Service e devolve a resposta HTTP. O Controller não conversa direto com o Repository.
- As rotas seguem o padrão REST. Vocês escolhem os nomes.

2. Model – Classe Sala
Crie o arquivo Sala.java dentro do pacote model.

Essa classe representa uma sala da escola.


java

package escola.model;

import jakarta.persistence.*;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;

@Entity
public class Sala {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @NotBlank(message = "O código é obrigatório")
    @Column(unique = true, nullable = false)
    private String codigo;

    @NotBlank(message = "O nome é obrigatório")
    @Column(nullable = false)
    private String nome;

    @Min(value = 1, message = "A capacidade deve ser maior que zero")
    private int capacidade;

    private boolean reservada = false;

    public Sala() {
    }

    public Long getId() {
        return id;
    }

    public String getCodigo() {
        return codigo;
    }

    public void setCodigo(String codigo) {
        this.codigo = codigo;
    }

    public String getNome() {
        return nome;
    }

    public void setNome(String nome) {
        this.nome = nome;
    }

    public int getCapacidade() {
        return capacidade;
    }

    public void setCapacidade(int capacidade) {
        this.capacidade = capacidade;
    }

    public boolean isReservada() {
        return reservada;
    }

    public void setReservada(boolean reservada) {
        this.reservada = reservada;
    }
}
Explicação:

@Entity: informa ao Spring/JPA que essa classe representa uma tabela no banco.

@Id: identifica o campo que será a chave primária.

@GeneratedValue: gera o ID automaticamente.

@NotBlank: impede código ou nome vazio.

@Column(unique = true): impede códigos duplicados no banco.

@Min(1): exige capacidade maior ou igual a 1.

reservada = false: toda sala começa livre.

4. Service – Regras de negócio
Essa é uma das partes mais importantes da prova.

Crie SalaService.java dentro do pacote service.

Aqui ficam as regras da escola, como impedir reservas duplicadas e impedir a exclusão de salas reservadas.


java

package escola.service;

import escola.model.Sala;
import escola.repository.SalaRepository;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class SalaService {

    private final SalaRepository repository;

    public SalaService(SalaRepository repository) {
        this.repository = repository;
    }

    // Cadastrar sala
    public Sala cadastrar(Sala sala) {

        if (repository.existsByCodigo(sala.getCodigo())) {
            throw new RuntimeException("Código já cadastrado");
        }

        sala.setReservada(false);

        return repository.save(sala);
    }

    // Listar todas as salas
    public List<Sala> listar() {
        return repository.findAll();
    }

    // Buscar sala pelo ID
    public Sala buscarPorId(Long id) {

        return repository.findById(id)
                .orElseThrow(() ->
                    new RuntimeException("Sala não encontrada"));
    }

    // Reservar sala
    public Sala reservar(Long id) {

        Sala sala = buscarPorId(id);

        if (sala.isReservada()) {
            throw new IllegalStateException(
                "Esta sala já está reservada");
        }

        sala.setReservada(true);

        return repository.save(sala);
    }

    // Liberar sala
    public Sala liberar(Long id) {

        Sala sala = buscarPorId(id);

        if (!sala.isReservada()) {
            throw new IllegalStateException(
                "Esta sala já está livre");
        }

        sala.setReservada(false);

        return repository.save(sala);
    }

    // Excluir sala
    public void excluir(Long id) {

        Sala sala = buscarPorId(id);

        if (sala.isReservada()) {
            throw new IllegalStateException(
                "Não é possível excluir uma sala reservada");
        }

        repository.delete(sala);
    }
}

package escola.controller;

import escola.model.Sala;
import escola.service.SalaService;

import jakarta.validation.Valid;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/salas")
public class SalaController {

    private final SalaService service;

    public SalaController(SalaService service) {
        this.service = service;
    }

    // Cadastrar sala
    @PostMapping
    public ResponseEntity<Sala> cadastrar(
            @Valid @RequestBody Sala sala) {

        Sala novaSala = service.cadastrar(sala);

        return ResponseEntity
                .status(HttpStatus.CREATED)
                .body(novaSala);
    }

    // Listar salas
    @GetMapping
    public ResponseEntity<List<Sala>> listar() {

        return ResponseEntity.ok(service.listar());
    }

    // Buscar sala pelo ID
    @GetMapping("/{id}")
    public ResponseEntity<Sala> buscar(@PathVariable Long id) {

        return ResponseEntity.ok(service.buscarPorId(id));
    }

    // Reservar sala
    @PutMapping("/{id}/reservar")
    public ResponseEntity<Sala> reservar(@PathVariable Long id) {

        return ResponseEntity.ok(service.reservar(id));
    }

    // Liberar sala
    @PutMapping("/{id}/liberar")
    public ResponseEntity<Sala> liberar(@PathVariable Long id) {

        return ResponseEntity.ok(service.liberar(id));
    }

    // Excluir sala
    @DeleteMapping("/{id}")
    public ResponseEntity<Void> excluir(@PathVariable Long id) {

        service.excluir(id);

        return ResponseEntity.noContent().build();
    }
}
Explicação dos principais comandos:

@RestController: transforma a classe em um controlador REST.

@RequestMapping("/salas"): define o endereço principal.

@PostMapping: recebe cadastros.

@GetMapping: recebe consultas.

@PutMapping: atualiza o estado da sala.

@DeleteMapping: exclui uma sala.

@RequestBody: recebe os dados JSON.

@PathVariable: recebe o ID informado na URL.

@Valid: executa as validações da Model.

ResponseEntity: permite controlar o status HTTP.

6. Tratamento de erros HTTP
Esta etapa é muito importante para a prova.

Precisamos garantir que a API responda:

400: dados inválidos.

404: sala não encontrada.

409: conflito, como reservar uma sala já reservada.

Para isso, vamos criar mais uma classe dentro do pacote controller, chamada TratamentoErros.java.

Primeiro, façam uma pequena alteração na Service.

No método cadastrar, substituam:


java
throw new RuntimeException("Código já cadastrado");
Por:


java
throw new IllegalStateException("Código já cadastrado");
Assim, tanto o código duplicado quanto as outras regras de conflito serão tratados como HTTP 409.

Agora criem TratamentoErros.java:


java

package escola.controller;

import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.Map;

@RestControllerAdvice
public class TratamentoErros {

    // Dados inválidos: 400
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, String>> dadosInvalidos(
            MethodArgumentNotValidException erro) {

        String mensagem = erro.getBindingResult()
                .getFieldErrors()
                .stream()
                .findFirst()
                .map(e -> e.getDefaultMessage())
                .orElse("Dados inválidos");

        return ResponseEntity
                .badRequest()
                .body(Map.of("erro", mensagem));
    }

    // Conflitos: 409
    @ExceptionHandler({
        IllegalStateException.class,
        DataIntegrityViolationException.class
    })
    public ResponseEntity<Map<String, String>> conflito(
            RuntimeException erro) {

        return ResponseEntity
                .status(HttpStatus.CONFLICT)
                .body(Map.of("erro", erro.getMessage() == null
                        ? "Conflito"
                        : erro.getMessage()));
    }

    // Sala não encontrada: 404
    @ExceptionHandler(RuntimeException.class)
    public ResponseEntity<Map<String, String>> naoEncontrado(
            RuntimeException erro) {

        return ResponseEntity
                .status(HttpStatus.NOT_FOUND)
                .body(Map.of("erro", erro.getMessage()));
    }
}
Como funciona?

A anotação @RestControllerAdvice permite tratar erros que acontecem em diferentes Controllers.

Por exemplo:

O usuário tenta reservar a sala 1.

O Controller chama a Service.

A Service percebe que ela já está reservada.

A Service lança uma exceção.

O TratamentoErros captura a exceção e responde com HTTP 409.

Isso evita colocar regras de negócio dentro do Controller.

3. Service corrigida
Substitua o conteúdo de SalaService.java por este:


java

package escola.service;

import escola.model.Sala;
import escola.repository.SalaRepository;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class SalaService {

    private final SalaRepository repository;

    public SalaService(SalaRepository repository) {
        this.repository = repository;
    }

    public Sala cadastrar(Sala sala) {

        if (repository.existsByCodigo(sala.getCodigo())) {
            throw new ConflitoException("Código já cadastrado");
        }

        sala.setReservada(false);

        return repository.save(sala);
    }

    public List<Sala> listar() {
        return repository.findAll();
    }

    public Sala buscarPorId(Long id) {

        return repository.findById(id)
                .orElseThrow(() ->
                    new SalaNaoEncontradaException(
                        "Sala não encontrada"));
    }

    public Sala reservar(Long id) {

        Sala sala = buscarPorId(id);

        if (sala.isReservada()) {
            throw new ConflitoException(
                "Esta sala já está reservada");
        }

        sala.setReservada(true);

        return repository.save(sala);
    }

    public Sala liberar(Long id) {

        Sala sala = buscarPorId(id);

        if (!sala.isReservada()) {
            throw new ConflitoException(
                "Esta sala já está livre");
        }

        sala.setReservada(false);

        return repository.save(sala);
    }

    public void excluir(Long id) {

        Sala sala = buscarPorId(id);

        if (sala.isReservada()) {
            throw new ConflitoException(
                "Não é possível excluir uma sala reservada");
        }

        repository.delete(sala);
    }
}
4. Tratamento de erros corrigido
Substitua TratamentoErros.java por:


java

package escola.controller;

import escola.service.ConflitoException;
import escola.service.SalaNaoEncontradaException;

import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.Map;

@RestControllerAdvice
public class TratamentoErros {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, String>> dadosInvalidos(
            MethodArgumentNotValidException erro) {

        String mensagem = erro.getBindingResult()
                .getFieldErrors()
                .stream()
                .findFirst()
                .map(e -> e.getDefaultMessage())
                .orElse("Dados inválidos");

        return ResponseEntity.badRequest()
                .body(Map.of("erro", mensagem));
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    public ResponseEntity<Map<String, String>> jsonInvalido(
            HttpMessageNotReadableException erro) {

        return ResponseEntity.badRequest()
                .body(Map.of("erro", "JSON inválido"));
    }

    @ExceptionHandler(ConflitoException.class)
    public ResponseEntity<Map<String, String>> conflito(
            ConflitoException erro) {

        return ResponseEntity.status(HttpStatus.CONFLICT)
                .body(Map.of("erro", erro.getMessage()));
    }

    @ExceptionHandler(DataIntegrityViolationException.class)
    public ResponseEntity<Map<String, String>> integridade(
            DataIntegrityViolationException erro) {

        return ResponseEntity.status(HttpStatus.CONFLICT)
                .body(Map.of("erro", "Conflito nos dados cadastrados"));
    }

    @ExceptionHandler(SalaNaoEncontradaException.class)
    public ResponseEntity<Map<String, String>> naoEncontrado(
            SalaNaoEncontradaException erro) {

        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body(Map.of("erro", erro.getMessage()));
    }
}
Agora não existe mais o problema de qualquer erro inesperado ser automaticamente classificado como 404.
